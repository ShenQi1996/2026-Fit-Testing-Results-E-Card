# Contributing

This repository is maintained by Sam Qi (GitHub @ShenQi1996) for Secure Fit LLC.

## How to contribute

1. Branch from `main`. Use a `snake_case` name like `name_yyyy_mm_dd_purpose`.
2. Make a small change. Keep pull requests small.
3. Before you open a pull request, run `npm ci && npm run build`.
4. Never commit secrets or `.env` files.

Open a normal GitHub issue for bugs and ideas. Send security reports to SecureFit2024@gmail.com instead. See `SECURITY.md`.
