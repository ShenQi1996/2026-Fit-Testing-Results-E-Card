# Security Policy

## Supported versions

Only the latest code on `main` is supported.

| Version | Supported |
| --- | --- |
| Latest `main` | Yes |
| Older commits and branches | No |

## Reporting a vulnerability

Report security vulnerabilities privately by email to SecureFit2024@gmail.com.

Do not open a public GitHub issue, pull request, or discussion for a security report.

Please include:

- What the problem is
- How to reproduce it, if you can
- What you think the impact is

We aim to reply within 7 days. We will keep the report private while we look into it.
